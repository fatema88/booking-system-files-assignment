# 🏥 Healthcare Management System

A C++ based Healthcare Management System developed as part of **File Management and Processing (IS321) – Assignment 1**, Academic Year 2026/2027, at the Faculty of Computers and Artificial Intelligence, Cairo University.

The system allows an administrator to manage doctors and their appointments using binary file storage, fixed-length records, indexing techniques, and file management operations.

## 📌 Project Overview

The project implements a simple healthcare data management system that stores and manages:

- Doctors' information.
- Appointments assigned to doctors.
- Relationships between doctors and their appointments.

The system uses binary files to store records efficiently and implements different indexing techniques to support fast searching and data retrieval.

## ✨ Features

### 1. Doctor Management
- Add new doctors.
- Print doctor information.
- Update doctor information.
- Delete doctors using logical deletion.
- Search for doctors using Doctor ID.

### 2. Appointment Management
- Add new appointments.
- Print appointment information.
- Update appointment information.
- Delete appointments using logical deletion.
- Search for appointments using Doctor ID.

### 3. File Management
- Binary file storage.
- Fixed-length records.
- Header records for Available List management.
- Logical deletion using the `*` marker.
- Reuse deleted record locations instead of appending new records every time.

### 4. Indexing Techniques

The project implements five indexes:

| Index | Data File | Key |
|---|---|---|
| Primary Index | Doctors | Doctor ID |
| Primary Index | Appointments | Appointment ID |
| Secondary Index | Appointments | Doctor ID |
| Secondary Index | Doctors | Doctor Name |
| Secondary Index | Doctors | Doctor Specialty |

All indexes are sorted in ascending order, and Binary Search is used for searching.

Secondary indexes are implemented using the linked-list-on-a-different-file technique, with integer pointers linking secondary index entries to the primary index.

### 5. Available List

The system uses an Available List to manage logically deleted records.

- Deleted records are marked with `*`.
- The deleted record's offset is stored in the Available List.
- The header stores the offset of the first available record.
- New records reuse available locations whenever possible.
- If no deleted location is available, new records are appended to the end of the file.

### 6. Query Engine

The system supports keyword-based queries that use the appropriate indexes to retrieve information.

Examples:

```sql
SELECT * FROM Doctors WHERE Doctor ID='xxx';

SELECT * FROM Appointments WHERE Doctor ID='xxx';

SELECT Doctor Name FROM Doctors
WHERE Doctor Name='xxx';

SELECT * FROM Doctors
WHERE Doctor Name='xxx'
AND Doctor Specialty='yyy';
```

## 🗂️ Record Structure

All records are stored in binary format using fixed-length fields.

### Doctor Record – 95 Bytes

| Field | Size |
|---|---:|
| Doctor ID | 15 bytes |
| Doctor Name | 30 bytes |
| Specialty | 20 bytes |
| Address | 30 bytes |
| **Total** | **95 bytes** |

### Appointment Record – 60 Bytes

| Field | Size |
|---|---:|
| Appointment ID | 15 bytes |
| Appointment Date | 30 bytes |
| Doctor ID | 15 bytes |
| **Total** | **60 bytes** |

Each data file starts with a 4-byte integer header representing the beginning of its Available List. Its initial value is `-1`.

## 🚀 How to Compile and Run

Make sure you have a C++ compiler installed, such as GCC.

Compile the project:

```bash
g++ -std=c++17 Healthcaresystem2.cpp Doctors.cpp Appointment.cpp FileUtilities.cpp -o HealthcareSystem
```

Run the application:

**Windows:**
```bash
HealthcareSystem.exe
```

**Linux / macOS:**
```bash
./HealthcareSystem
```
